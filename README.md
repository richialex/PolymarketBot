# PolymarketBot

Бот для автоматического фарминга LP-наград на [Polymarket](https://polymarket.com).

Бот размещает лимитные ордера в reward zone предсказательных рынков и пассивно зарабатывает вознаграждения за предоставление ликвидности. Ищет "мёртвые" рынки с минимальной конкуренцией и максимальным reward/liquidity ratio.

---

## Как это работает

- Сканирует все рынки с активными наградами на Polymarket
- Оценивает каждый рынок по формуле: `score = (daily_reward / zone_liquidity) × activity_factor`
- Размещает BUY ордера внутри reward zone
- Следит за стаканами и своими ордерами через WebSocket; обычный мониторинг позиций остаётся как REST fallback
- Быстро уводит открытый BUY с опасного уровня, если ордер оказался не там, где должен быть
- Автоматически переключается на более выгодные рынки

## Требования

- **Python 3.11+**
- **Аккаунт Polymarket** с пополненным балансом в USDC (сеть Polygon)
- **API ключи Polymarket** (получить на polymarket.com в настройках профиля)
- Windows / Linux / Mac

## Установка с нуля

### 1. Установи Python 3.11+

Скачай с [python.org](https://www.python.org/downloads/) и установи.  
При установке на Windows поставь галочку **"Add Python to PATH"**.

Проверь:
```bash
python --version
# Python 3.11.x
```

### 2. Скачай бот

```bash
git clone https://github.com/ggRonin/PolymarketBot.git
cd PolymarketBot
```

Или скачай ZIP через кнопку **Code → Download ZIP** на этой странице и распакуй.

### 3. Создай виртуальное окружение

```bash
python -m venv .venv
```

Активируй:
- **Windows:** `.venv\Scripts\activate`
- **Linux/Mac:** `source .venv/bin/activate`

### 4. Установи зависимости

```bash
pip install -e .
```

### 5. Получи API ключи Polymarket

1. Зайди на [polymarket.com](https://polymarket.com) и войди в аккаунт
2. Перейди в **Profile → Settings → API Keys**
3. Создай новый ключ — скопируй `API Key`, `Private Key` и адрес кошелька

### 6. Настрой .env файл

Скопируй шаблон:
```bash
cp .env.example .env
```

Открой `.env` и заполни:
```env
WALLET_ADDRESS=0xТвойАдресКошелька
API_KEY=твой-api-ключ
KEYSTORE_FILE=secrets/wallet.json
```

Создай зашифрованное хранилище приватного ключа (ввод ключа и пароля скрыт):

```bash
python -m src.keystore create --file secrets/wallet.json
```

После успешного создания удали строку `PRIVATE_KEY` из `.env`. При каждом запуске
приложение запросит пароль от keystore в терминале; пароль не хранится в `.env`.
Файл `secrets/` уже исключён из Git.

Чтобы сверить, какой публичный адрес соответствует keystore, не раскрывая ключ:

```bash
python -m src.keystore address --file secrets/wallet.json
```

### 7. Запусти бот

**Windows:**
```
Дважды кликни start.bat
```

**Linux/Mac:**
```bash
python -m uvicorn src.main:app --port 8000
```

Открой браузер: **http://localhost:8000**

## Настройки

Все параметры меняются через веб-интерфейс без перезапуска бота.

| Параметр | Описание | По умолчанию |
|----------|----------|-------------|
| **Глубина ордера** | Куда ставить BUY внутри reward zone: край диапазона / середина / первая позиция | Край диапазона |
| **USDC на позицию** | Фиксированный бюджет одного нового BUY-входа бота | 10 |
| **Макс. капитал бота, USDC** | Суммарный лимит капитала в BUY-позициях, которыми управляет бот | 100 |
| **Макс. отмен при ребалансе** | Сколько худших рабочих ордеров бот может отменить за один ребаланс | 2 |
| **Мин. дневная награда, $** | Минимальная дневная награда рынка для входа | 7.0 |
| **Интервал сканирования, сек** | Как часто сканер ищет новые reward-рынки | 60 |
| **Режим поиска рынков** | Источник поиска рынков: Legacy SDK или Multi `/rewards/markets/multi` | Legacy |
| **Порог волатильности** | Макс. стандартное отклонение цены за 24ч (0.05 = 5%) | 0.05 |
| **Мин. спред, ¢** | Мин. ширина reward zone в центах | 2.0 |
| **Макс. спред стакана, ¢** | Макс. реальный bid-ask спред; фильтр ликвидности | 2.0 |
| **Макс. глубина bid, ¢** | Макс. разница между 1-м и 4-м bid-уровнем токена для покупки | 4.0 |
| **Макс. доля уровня, %** | Макс. доля точного целевого bid-уровня, которую может занимать BUY бота | 50 |
| **Подтверждение доли, сек** | Сколько секунд превышение доли уровня должно держаться перед уменьшением/отменой BUY | 5 |
| **Макс. сделок в день** | Макс. изменений цены за день; более активные рынки пропускаются | 3 |
| **Проверка позиций, сек** | Интервал обычного мониторинга; WS-события могут сработать быстрее | 5 |
| **Фильтр слов** | Слова через запятую — рынки с ними пропускаются | — |

Поля старой модели `% на позицию`, `Макс. $ на ордер` и `Макс. позиций` оставлены как legacy и больше не управляют текущей моделью капитала.

## Стратегия

Бот ищет **"мёртвые" рынки** — где цена почти не двигается. В таких рынках:
- Ордер долго висит в reward zone и накапливает награды
- Низкая конкуренция → большая доля наград достаётся нам
- Минимальный риск исполнения ордера

Награды Polymarket считаются по **количеству шейрсов**, а не по вложенным долларам:
```
Score = ((max_spread - order_spread) / max_spread)² × order_size_in_shares
```

## Важно

- Бот работает с **реальными деньгами** — начни с небольшой суммы
- Установи **"USDC на позицию"** и **"Макс. капитал бота, USDC"** чтобы контролировать риск
- Используй **фильтр слов** чтобы исключить нежелательные категории рынков (politics, russia и т.д.)
- При остановке бота открытые ордера остаются на Polymarket — закрой их вручную или через кнопку "Отменить все"
